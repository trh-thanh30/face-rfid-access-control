# Reliability profile `wp09-v1`

Profile này khóa timing cho WP09. Giá trị mặc định được khai báo bằng code tại `packages/shared/src/reliability-profile.ts`; API từ chối `RELIABILITY_PROFILE_VERSION` khác version này.

| Setting                 |                                          Giá trị |
| ----------------------- | -----------------------------------------------: |
| Heartbeat interval      |                                        10,000 ms |
| Offline threshold       |                                        30,000 ms |
| Auth Session TTL        |                                        10,000 ms |
| Actuation Command TTL   |                                         5,000 ms |
| Open duration           |                                         3,000 ms |
| Poll initial/max        |                                   250 / 1,000 ms |
| Simulator poll deadline |         12,000 ms, vẫn bị chặn bởi server expiry |
| ACK retry/max attempts  |                   1,000 ms / 5 lần trong một run |
| Vision request timeout  | 10,000 ms, đồng thời không vượt session deadline |

Firmware giữ ACK trong NVS và tiếp tục retry ở các loop/run sau, nên `ackMaxAttempts` chỉ là giới hạn của một simulator run. Thay đổi một giá trị cần tạo profile version mới và cập nhật API, simulator, firmware cùng evidence; không sửa âm thầm profile đã khóa.

## Correlation và latency

- Mỗi Auth Session có một `correlationId`, được dùng trên Decision/Actuation event và request Vision.
- API log structured event `auth_session_response`, `auth_session_poll`, `actuation_ack` mà không chứa token/embedding.
- Decision event `latencyMs` là thời gian server từ tạo session đến quyết định; `metadata.visionLatencyMs` giữ span Vision.
- Actuation event `latencyMs` là thời gian từ Decision đến API nhận ACK; device timestamp được giữ riêng trong metadata.
